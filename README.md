Token Radar: a ranked board of genuine pre-token protocols, scored by implied value — what a token would be worth if the protocol's record stayed as it is. Reads a sealed snapshot, scores every protocol with a deterministic model, and writes the ranked board plus a dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
